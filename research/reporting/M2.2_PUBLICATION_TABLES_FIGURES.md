# M2.2 — Publication Tables and Figures

## Purpose

M2.2 turns the frozen M1 endpoint into compact publication assets.

It is presentation-only. No model is loaded, no candidate is rescored, no
bootstrap is rerun, and no new statistical decision is made.

## Source gate

Generation requires exact matches for all three authoritative M1 endpoint
artifacts frozen in M2.1:

- final M1 manifest;
- final M1 summary;
- final M1 Markdown result.

If any SHA-256 differs, generation aborts.

## Numeric snapshot

The reporting module contains a compact numeric snapshot of already-frozen M1
point estimates. This intentionally avoids importing evaluation or inference
code into the publication layer.

The snapshot includes:

- 12 primary macro NDCG@10 values;
- 8 primary Popularity pairwise margins;
- 8 support-sensitivity score rows;
- primary/shared-tabs/tab1 randomized-minus-standard `G_AB` estimates for
  Popularity minus BPR, both native and matched-user.

These values are not recomputed.

## Outputs

`runs/m2/publication/` contains:

- `primary_scores.csv`
- `primary_popularity_margins.csv`
- `support_sensitivity_scores.csv`
- `regime_G_popularity_minus_bpr.csv`
- `primary_scores.svg`
- `regime_margin.svg`
- `manifest.json`

The manifest records SHA-256 values for every generated publication asset.

## Figure interpretation

`primary_scores.svg` shows the four primary regime-target cells and the three
frozen model point estimates.

`regime_margin.svg` shows how the Popularity-minus-BPR margin changes from
standard to randomized exposure under the primary support and both support
sensitivities. Native and matched-user estimates are displayed separately.

The regime-margin figure is an offline evaluation contrast. It must not be
described as a causal effect of the logging policy.
