# M1.5 — Frozen Support-Sensitivity Raw Evaluation

## Scope

M1.5 evaluates the two support restrictions pre-specified in M0.15.

### Sensitivity A: shared tabs

Primary shared-user/shared-video support is further restricted to the tabs
shared across logging regimes:

`{1, 2, 11, 14}`

This is a pre-specified support sensitivity.

### Sensitivity B: tab 1

Primary shared-user/shared-video support is further restricted to:

`tab = 1`

This is descriptive only because the public KuaiRand documentation does not
provide a semantic UI label for numeric tab IDs.

## Ordering of restrictions

The tab restriction is applied before repeated user-video exposure rows are
collapsed.

This matters because a user-video pair can appear under more than one tab.
Filtering a pair-collapsed table would leak excluded-tab relevance into the
sensitivity candidate.

The full order is:

1. derive shared users/videos from the standard and randomized evaluation logs;
2. restrict each regime to those shared users/videos;
3. restrict to the frozen sensitivity tab set;
4. restrict to M0.18 training-indexed users/items;
5. collapse repeated user-video rows with target-specific any-positive relevance;
6. score with the frozen checkpoints;
7. evaluate with M0.19 NDCG@10 semantics.

## Frozen model policy

M1.5 reuses exactly the M0 primary models:

- deterministic Popularity;
- BPR seeds 0-4;
- LightGCN seeds 0-4.

No model is retrained or retuned.

## Output boundary

M1.5 writes raw per-user sensitivity NDCG artifacts and mechanical cell
summaries only.

Inference and comparison to the primary result are deferred until the raw
sensitivity artifacts have been hash-verified.
