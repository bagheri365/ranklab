## Frozen contrast definitions

For models A and B:

`D_AB = S_A - S_B`

Logging-regime contrast:

`G_AB = D_AB(randomized) - D_AB(standard)`

Behavioral-target contrast:

`T_AB = D_AB(long_view) - D_AB(is_click)`

All three unordered model pairs are reported.

## Native contrast

The native procedure is primary.

For each cross-cell comparison:

1. form the union of user IDs eligible in either cell;
2. resample those union user IDs with replacement;
3. carry each sampled user's available observations in each cell;
4. recompute each cell's pairwise model margin on the sampled users available
   to that cell;
5. subtract margins according to the frozen G_AB or T_AB definition.

This preserves repeated-user dependence while retaining each cell's native
target/regime eligibility population.

## Matched-user sensitivity

M1.3 first restricts to users eligible in both cells, then resamples that
matched-user intersection directly and computes the paired difference in
per-user model margins.

This sensitivity asks how much the contrast changes when evaluated on a common
user population.

## Bootstrap

Frozen settings:

- nonparametric user bootstrap;
- 20,000 replicates;
- RNG seed 365;
- percentile intervals;
- 95% confidence.

G_AB and T_AB are effect-size estimates. Per M0.20, M1.3 does not attach a
second family of statistical-significance labels.

## Efficiency

The four cross-cell comparisons are bootstrapped once each:

- standard vs randomized for `is_click`;
- standard vs randomized for `long_view`;
- `is_click` vs `long_view` under standard logging;
- `is_click` vs `long_view` under randomized logging.

Within each resample, all three model-pair margins are computed together. This
preserves common resampling dependence and avoids redundant bootstrap work.
