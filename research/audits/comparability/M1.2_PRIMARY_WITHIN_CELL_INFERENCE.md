# M1.2 — Frozen Within-Cell Inference

## Status

M1.2 consumes the validated M1.1 raw per-user NDCG artifact.

It does not load model checkpoints, score candidates, retrain models, or alter
the frozen M0 protocol.

## Source artifact

Expected M1.1 raw SHA-256:

`25f41d6380964e0eaf0f6746a8e4df221a3c62faa105ce33a3893d92f1d4301a`

The run aborts if this digest changes.

## Frozen seed aggregation

For BPR and LightGCN, each eligible user's five NDCG values from seeds 0–4 are
averaged first.

Popularity remains deterministic.

The model point estimate is then the equal-user mean of those per-user values,
which is equivalent to the arithmetic mean of the five seed-specific macro
scores because the eligible population is model-independent.

## Frozen within-cell inference

For each of the four primary regime/target cells and each of the three unordered
model pairs, M1.2 computes:

- `D_AB = S_A - S_B`;
- paired nonparametric user bootstrap;
- 20,000 replicates;
- RNG seed 365;
- ordinary 95% percentile interval;
- Bonferroni simultaneous interval using the frozen 12-comparison primary family.

A decisive winner is assigned only according to the already-frozen M0.20 rule.

## Explicitly deferred

M1.2 does not yet compute:

- `G_AB`, the cross-logging-regime change in pairwise margin;
- `T_AB`, the cross-target change in pairwise margin;
- native union-user cross-cell intervals;
- matched-user cross-cell sensitivities.

Those belong to the next inference milestone because they require different
cross-cell resampling structures.

## Outputs

- `manifest.json`
- `per_user_seed_mean_ndcg.csv.gz`

The seed-mean per-user artifact is the canonical input to the later cross-cell
contrast stage.
