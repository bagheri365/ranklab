# M1.6 — Frozen Support-Sensitivity Inference

## Purpose

M1.6 consumes the two hash-verified M1.5 raw sensitivity artifacts.

Frozen source SHA-256 values:

- shared-tabs raw:
  `8700954a26b2c40b7abdc2a768c9e095f3ccbf360589fbd4e1f169b0ea0e85c7`
- tab-1 raw:
  `e832abb6f15a1876ad695bcb2bdcd6ed01e8f67ebbe91db5024972afb2e465dd`

Any source drift aborts inference.

## Seed treatment

BPR and LightGCN seeds 0-4 are averaged inside user before any bootstrap,
matching the frozen primary M0.20 procedure.

Popularity remains deterministic.

## Within-cell sensitivity reporting

Each sensitivity reports:

- macro NDCG@10 for all three models;
- descriptive model order;
- the three paired user-level model margins;
- 95% paired percentile-bootstrap intervals.

Sensitivity supports do **not** expand the frozen primary 12-comparison family.
Accordingly, M1.6 does not create a second decisive-winner testing family or
attach new decisive-winner labels to sensitivity cells.

## Cross-cell robustness contrasts

For each sensitivity, M1.6 also reuses the frozen cross-cell procedures:

- `G_AB = D_AB(randomized) - D_AB(standard)`;
- `T_AB = D_AB(long_view) - D_AB(is_click)`;
- native union-user bootstrap;
- matched-user paired sensitivity;
- 20,000 replicates;
- RNG seed 365;
- 95% percentile intervals.

These remain effect-size robustness estimates, not a new significance family.

## Interpretation roles

- `shared_tabs` is the pre-specified support sensitivity.
- `tab1` is descriptive only because public KuaiRand documentation does not
  provide a semantic UI label for tab ID 1.
