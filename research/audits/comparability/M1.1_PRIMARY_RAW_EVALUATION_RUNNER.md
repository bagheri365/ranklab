M1.1 implements the first permitted test-set scoring step under the frozen M0
protocol. It writes raw per-user metrics and seed-level validation summaries
only.

## Guardrails

Before any evaluation score is computed, the runner verifies:

1. exact frozen protocol bytes;
2. `research/protocol_frozen_m0.sha256`;
3. the identical protocol SHA in `configs/experiments/m1/primary.yaml`;
4. all five BPR checkpoint SHA-256 values;
5. all five LightGCN checkpoint SHA-256 values.

Any mismatch aborts the run.

## Candidate construction

The runner reuses the frozen code paths:

- M0.15 shared-user/shared-video primary support;
- M0.18 user/item membership in the pairwise training index;
- M0.19 unique user-video pair collapse;
- target-specific any-positive relevance;
- minimum two candidates;
- zero-relevance exclusion from target-specific macro NDCG;
- deterministic score-descending/video-id-ascending ranking;
- NDCG@10 with all available candidates when fewer than ten exist.

No test negatives are sampled.

## Model loading

Popularity is refit deterministically from all pair-collapsed positive Apr 9–16
training pairs, exactly as frozen in M0.14.

BPR uses `BPRMatrixFactorization.load`.

LightGCN uses `LightGCNModel.load`. For evaluation efficiency, the frozen final
propagated embeddings are computed once per checkpoint and cached; this changes
no scoring semantics.

## Raw artifact

`per_user_ndcg.csv.gz` contains one record for every:

- logging regime;
- behavioral target;
- model;
- stochastic seed where applicable;
- primary-support user.

Columns retain:

- user id;
- candidate count;
- relevant count;
- inclusion/exclusion status;
- exclusion reason;
- per-user NDCG@10 when defined.

This is the sufficient raw input for the M0.20 seed aggregation and user-level
bootstrap implemented in later M1 milestones.

## Explicitly not done in M1.1

M1.1 does not compute or declare:

- bootstrap confidence intervals;
- decisive winners;
- selection stability;
- model rank reversals;
- `G_AB`;
- `T_AB`;
- statistical significance;
- practical equivalence.

The manifest's cell/seed macro values are mechanical integrity summaries of the
raw artifact, not the final RankLab interpretation.
