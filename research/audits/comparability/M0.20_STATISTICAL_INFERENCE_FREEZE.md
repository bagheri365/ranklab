M0.20 freezes how RankLab interprets the already-frozen per-user NDCG outputs.
No M1 model metrics were inspected in choosing these rules.

## 1. Cross-seed estimand

BPR and LightGCN use frozen primary seeds:

`0, 1, 2, 3, 4`.

For each model/regime/target/support cell, the stochastic-model point estimate
is the arithmetic mean across the five frozen seed-specific macro NDCG values.

Because the target/candidate eligibility population is model-independent, this
is equivalent to averaging each eligible user's NDCG across seeds first and
then taking the user macro mean.

Popularity is deterministic and has no artificial replicated seed dimension.

Reports must also show seed-specific BPR/LightGCN values and descriptive seed
dispersion (sample SD and range). Seed dispersion is not substituted for
user-level uncertainty.

## 2. Descriptive model order

Within each evaluation cell, models are ordered by their point estimate,
descending.

Exact numeric ties are broken by model id only to make tables deterministic.
Such an exact tie must still be described as a tie substantively.

Descriptive order and inferentially decisive selection are separate concepts.

## 3. Pairwise margin

For models A and B:

`D_AB = S_A - S_B`

where S is the frozen model point estimate for the cell.

Positive D_AB favors A; negative D_AB favors B.

All three unordered model pairs are reported.

## 4. Logging-regime contrast

For a fixed target:

`G_AB = D_AB(randomized) - D_AB(standard)`.

G_AB therefore measures how the pairwise model advantage changes when the
logging/exposure regime changes.

A sign change in D_AB across regimes is a descriptive rank reversal.

## 5. Behavioral-target contrast

For a fixed logging regime:

`T_AB = D_AB(long_view) - D_AB(is_click)`.

T_AB measures how the pairwise model advantage changes when the behavioral
target changes.

A sign change in D_AB across targets is a descriptive target-based reversal.

## 6. No post-hoc practical delta

RankLab sets no nonzero practical-difference threshold.

Reason:

Choosing an NDCG delta after observing M1 effects would make the stability
criterion outcome-dependent. There is no externally justified RankLab-specific
NDCG threshold available from M0.

Therefore:

- raw effect sizes are always reported;
- uncertainty intervals are reported;
- no effect is relabeled practically zero using a data-selected epsilon.

## 7. Bootstrap

Primary uncertainty uses a user-cluster nonparametric bootstrap.

Frozen settings:

- replicate count: 20,000;
- RNG seed: 365;
- base confidence level: 95%.

For a within-cell model comparison, resampling is paired by user: the same
resampled users contribute to both models.

For BPR/LightGCN, each user's five frozen seed-specific NDCGs are averaged
inside the user before bootstrap resampling. The seed set is treated as the
fixed primary training ensemble/replication set; the user bootstrap estimates
population uncertainty conditional on those frozen training seeds.

Seed-specific results remain visible so training stochasticity is not hidden.

## 8. Primary multiplicity family

The primary support has:

- 2 logging regimes;
- 2 behavioral targets;
- 3 unordered model pairs.

Therefore there are 12 primary within-cell pairwise model comparisons.

For decisive winner claims, RankLab controls familywise confidence by a
Bonferroni simultaneous interval rule across these 12 comparisons:

`individual alpha = 0.05 / 12`.

Equivalently, each primary pairwise interval used for a decisive claim has
confidence:

`1 - 0.05/12 = 99.583333...%`.

Ordinary 95% intervals may additionally be reported for readability, but they
must not be used for the phrase "decisive winner".

Sensitivity-support comparisons are reported as robustness analyses and do not
expand the primary 12-comparison family.

## 9. Decisive winner

Within a regime/target primary cell, model A is a decisive winner only if:

1. A has the largest point estimate; and
2. the Bonferroni-simultaneous interval for A minus each of the other two
   models is strictly above zero.

Otherwise the cell's decisive winner is `indeterminate`.

## 10. Selection stability labels

For two cells being compared:

- `stable`: both have a decisive winner and it is the same model;
- `decisive_change`: both have decisive winners and they are different models;
- `indeterminate`: at least one cell has no decisive winner.

Separately, descriptive rank/order changes are always reportable even when the
decisive label is indeterminate.

## 11. Seed-order stability

For BPR/LightGCN stochasticity, RankLab also reports the model order for each
of the five frozen seeds.

A descriptive `seed_order_agreement` flag is true only when all five seed-level
orders are identical.

This is descriptive and does not replace the user bootstrap.

## 12. Native cross-cell contrasts

For G_AB and T_AB on each cell's native target-eligible user population,
uncertainty uses a user-cluster bootstrap over the union of relevant user IDs.

A resampled user carries all of that user's available cell/model observations.
This preserves cross-cell dependence when the same user contributes to both
cells while allowing eligibility to differ across cells.

These native contrasts answer the primary estimand because M0.19 intentionally
lets zero-relevance eligibility differ by regime/target.

## 13. Matched paired sensitivity

Every G_AB and T_AB additionally receives a matched-user sensitivity analysis.

The matched analysis restricts to user IDs eligible for both cells entering the
contrast, then performs a paired user bootstrap on that intersection.

This separates changes in model margin on a common user population from changes
partly associated with target/regime-specific metric eligibility.

The native clustered contrast remains primary; matched paired is sensitivity.

## 14. Confidence intervals for G_AB and T_AB

G_AB and T_AB receive 95% bootstrap percentile intervals and raw effect sizes.

They are interpreted as estimation intervals rather than a second family of
winner hypothesis tests. RankLab does not attach additional "statistically
significant" labels to G_AB/T_AB.

## 15. CI method

Frozen CI method:

`nonparametric percentile bootstrap`.
