# M0.3 — Shared-support and scenario audit

## Status

**Descriptive only. Nothing in this artifact freezes the M1 matched-support rule.**

## Purpose

M0.2 showed large native differences in target prevalence and scenario composition between the standard-policy and randomized evaluation logs. M0.3 measures how those differences change under increasingly comparable descriptive slices.

The audit reports:

1. native evaluation logs;
2. shared users + shared videos;
3. shared users + shared videos + shared `tab` values;
4. a `tab=1` descriptive slice when available.

## Official `tab` semantics

The KuaiRand README documents `tab` as a scenario identifier in `[0, 14]` and gives examples such as recommendation-page or main-page scenarios, but it does **not** publicly map each numeric ID to a semantic scenario name.

Therefore RankLab must not label `tab=1` as a particular UI without additional authoritative evidence. It is analyzed only because it is shared and dominant in the randomized log.

## Interpretation rule

M0.3 may identify candidate restrictions for later freezing, but no restriction becomes primary merely because it makes target prevalence or model behavior look more similar across regimes.
